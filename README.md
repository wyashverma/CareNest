# CareNest web (demo)

Healthcare marketplace frontend. React + Vite + TypeScript + Tailwind + React Router + Lucide.

    npm install
    npm run dev        # http://localhost:5173
    npm run build      # type-check + production build

All data is mock/demo. Set `VITE_USE_MOCK=false` (see `.env.example`) once real REST endpoints exist;
services in `src/services` are the only place that needs to change.
